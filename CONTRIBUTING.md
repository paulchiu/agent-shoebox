# Contributing

Contributions should keep Agent Shoebox small, portable, and agent-agnostic.

Useful changes usually improve one of these areas:

- clearer archive conventions;
- safer redaction or commit behaviour;
- portable hook examples;
- compatibility with more agent runtimes without hard-coding a specific one.

Please avoid adding generated personal archive content, credentials, raw
transcripts, or examples that depend on a private local path.
